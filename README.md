# CodeMl2026-DayOne

Solution du défi DayOne : assistant hors ligne pour sages-femmes.

## Objectif

Documenter l’architecture hors ligne, les sources permises, les scénarios de validation et les limites du prototype.

## Organisation du dépôt

Le dépôt est un point de départ. Le code, les instructions de reproduction et les décisions de conception seront ajoutés après revue des fichiers de travail et des règles du défi.

## Données et confidentialité

Ne pas committer de dossiers personnels, données cliniques, documents non autorisés, secrets ou credentials. Les règles officielles du défi déterminent ce qui peut être partagé. Ajouter uniquement des données explicitement autorisées; privilégier des exemples synthétiques et des scripts qui téléchargent les données depuis leur emplacement approuvé.

## Reproduction

À compléter lorsque l’environnement et les commandes de lancement auront été vérifiés.
